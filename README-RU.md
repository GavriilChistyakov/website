# Astra Lemania — полный исходный код сайта

Снимок опубликованной версии от 15 октября 2026 года. Комментарии и форматирование добавлены в эту копию; опубликованный сайт не изменён.

## Быстрый старт

1. Распакуйте весь архив.
2. Откройте index.html в браузере. Для проверки через локальный сервер, если установлен Python: `python -m http.server 8000`, затем http://localhost:8000.
3. Редактируйте HTML/CSS/JS в любом редакторе кода с UTF-8.
4. Для размещения на обычном статическом хостинге загрузите содержимое этой папки, сохранив структуру assets. Сборка, npm, база данных и серверный код не нужны.

## Остальные файлы

- style.css — все стили, адаптивная компоновка, цвета, анимация, прозрачность и fade.
- site.js — определение iOS/iPadOS и переключение вида стрелок.
- assets/fonts.css и файлы .ttf — локальные Montserrat и Nunito Sans. Myriad Pro не поставляется.
- IMAGES.md — точные имена, размеры и расположение всех действующих изображений.
- SOURCE-VERSION.txt — версия исходников, из которой сделан экспорт.

## Где что менять

**Тексты:** непосредственно в нужном HTML между тегами. Перевод не автоматический: изменяйте также английский файл.

**Email:** найдите contact@astralemania.ch во всех восьми HTML. Меняйте и видимый текст, и `href="mailto:..."`. Отдельной формы отправки нет — открывается почтовое приложение посетителя.

**Адрес:** contact.html и en-contact.html, блок class="address".

**Логотип и меню:** header повторяется на каждой странице; изменяйте все восемь файлов. В английской версии используется тот же официальный логотип с французской подписью.

**Цвета:** переменные :root в style.css: --green #234a40, --ivory #f5f1e8, --sand #c9b79f. Цвета внутри PNG меняются в самих изображениях, не через эти переменные.

**Кнопки:** class="button" в HTML; href задаёт назначение. Оформление в style.css. Дополнительный класс light обозначает светлую кнопку на зелёном фоне.

**Главная иллюстрация:** .hero-art img. На телефонах она прозрачная и находится за текстом. Ищите последнее правило внутри @media(max-width:700px).

**Портрет:** .founder-portrait img; плавное исчезновение снизу задают mask-image и -webkit-mask-image. Они не удаляют белые края из самого файла — для замены нужен аккуратный PNG.

**Фоновый знак Contact:** .contact-star. left/right и bottom управляют положением; width — размером; opacity — прозрачностью; mask-image — затуханием. Ниже есть отдельные настройки для телефона.

**Невысокие ноутбуки:** @media(min-width:701px) and (max-height:850px) уменьшает отступы, заголовки и кнопки.

**Язык:** блок language-switch в шапке. FR / EN ведут на соответствующую страницу. Выбранный язык сохраняется переходами внутри этой версии; автоматического определения языка нет.

**Анимация:** text-rise и prefers-reduced-motion. При системном ограничении анимации эффект отключается.

## Важно про CSS

В файле сохранён каскад действующего сайта: некоторые селекторы встречаются несколько раз. Поздние правила могут переопределять ранние; мобильные правила действуют только при соответствующей ширине. Для небольших правок можно добавить своё правило в самый конец style.css, отдельно указав @media при необходимости.

## Проверка после изменений

Проверьте обе языковые версии, ссылки меню, почтовые кнопки, ширины телефона и компьютера. Отдельно проверьте iPhone/iPad: скрипт заменяет стрелки только там. Прямые ссылки .html работают на обычном статическом хостинге; адреса без .html требуют настройки конкретного сервера.

Сайт статический. Доступы к хостингу, токены и служебная история Git в архив не включены. Этот экспорт не привязан к конкретному хостингу.
