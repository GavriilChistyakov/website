FAVICON ASTRA LEMANIA

1. Скопируйте favicon.ico и все PNG из архива в корень сайта рядом с index.html.
2. В каждом из восьми HTML добавьте код из HEAD-CODE.txt перед </head>.
   Если уже есть link rel="icon" или apple-touch-icon, замените их, не дублируйте.
3. Загрузите изменённые HTML на хостинг.
4. Откройте https://astralemania.ch/favicon.ico и убедитесь, что файл доступен.
5. Закройте вкладку и откройте сайт заново. При необходимости очистите кеш сайта.

Использован присланный знак без перерисовки, с прозрачным фоном и сохранёнными пропорциями.
favicon.ico содержит 16, 32, 48, 64, 128 и 256 px для разных масштабов браузера.
PNG 32/48/192/512 — дополнительные размеры; apple-touch-icon.png — 180 px.
Файлы 32 и 512 px оставлены как дополнительные варианты, в HEAD-CODE.txt не подключаются.

Изменения не опубликованы автоматически на astralemania.ch.
