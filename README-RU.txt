Это полные файлы, не фрагменты кода. Основа — HTML, скачанный с astralemania.ch в момент подготовки.

1. Сохраните резервную копию текущих файлов хостинга.
2. Замените восемь HTML одноимёнными файлами из архива:
   index.html, expertises.html, a-propos.html, contact.html,
   en-index.html, en-expertises.html, en-a-propos.html, en-contact.html.
   Можно открыть каждый файл в редакторе и скопировать ВСЁ содержимое вместо старого кода.
3. Добавьте robots.txt и sitemap.xml в корень сайта, рядом с index.html.
   Если эти файлы появились на хостинге после нашей проверки, сначала сравните их содержимое.
4. style.css, site.js и папку assets НЕ удаляйте и НЕ заменяйте: они нужны этим HTML и не менялись.
5. Проверьте главную, страницы FR/EN, изображения и ссылки. Убедитесь, что
   https://astralemania.ch/robots.txt и https://astralemania.ch/sitemap.xml открываются.
6. Подтвердите домен в Google Search Console через выданную Google DNS TXT-запись.
   Отправьте sitemap.xml и проверьте URL главной и a-propos.html через инспекцию URL.

Изменения:
- индивидуальные title и meta description на всех восьми страницах;
- canonical каждой страницы на её собственный адрес astralemania.ch;
- полные взаимные FR/EN ссылки hreflang и x-default на французскую версию;
- JSON-LD Organization, Person, WebSite и описание текущей страницы;
